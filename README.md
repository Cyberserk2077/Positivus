# Positivus

Responsive landing page for a digital marketing agency built with HTML, SCSS and JavaScript.

## Live Demo

[View website](https://cyberserk2077.github.io/positivus/)

## About

Positivus is a responsive landing page for a digital marketing agency.

The project was created from a design layout and includes adaptive sections, interactive navigation, modal windows and a reviews slider.

## Features

- Responsive layout
- Mobile navigation
- Reviews slider
- Modal windows
- Contact form interface
- Reusable SCSS components
- Adaptive typography and spacing

## Technologies

- HTML5
- SCSS
- CSS3
- JavaScript
- Git
- GitHub Pages

```bash
git clone git@github.com:Cyberserk2077/positivus.git
